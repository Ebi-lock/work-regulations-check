# 必須記載事項チェックリスト（労働基準法第89条）

就業規則に「何が書かれていなければならないか」の基準。
記載の有無だけでなく、**記載が具体的で運用可能か**も見る。
「別途定める」で終わっている項目は、その別規程が無ければ記載漏れと同じ状態になる。

## 絶対的必要記載事項（必ず書く。無ければ法89条違反）

### 1. 労働時間関係（89条1号）

| 項目 | 確認すること | よくある不備 |
|---|---|---|
| 始業・終業の時刻 | 具体的な時刻が書かれているか | 「所定労働時間は8時間とする」だけで時刻が無い |
| 休憩時間 | 長さと与え方。6時間超で45分、8時間超で60分以上（34条） | 8時間勤務で休憩45分のまま（残業すると違法になる） |
| 休日 | 毎週1日または4週4日（35条）。法定休日がどれか特定できるか | 「土日祝」とあるが法定休日が日曜か土曜か不明 |
| 休暇 | 年次有給休暇（39条）、産前産後（65条）、生理日（68条）、子の看護等休暇・介護休暇（育介法） | 法定休暇の記載漏れ、付与日数が法定を下回る |
| 交替制の就業時転換 | 交替制がある場合、交替順序・勤務時間帯の転換の仕方 | 交替制なのに記載が無い |
| 変形労働時間制・フレックス | 採用しているなら種類・清算期間・コアタイム等（32条の2〜32条の5） | 運用しているが就業規則に根拠が無い（＝制度が無効） |

**年次有給休暇で必ず見る点**
- 付与要件: 雇入れ6か月継続勤務・全労働日の8割以上出勤 → 10日（39条1項）
- 継続勤務年数に応じた加算（1年6か月=11日 … 6年6か月以上=20日）
- 比例付与（週所定労働日数4日以下かつ週30時間未満のパート等）の規定があるか
- 時季変更権（39条5項）の書き方が「会社が認めた場合に取得できる」になっていないか → 許可制は違法
- **年5日の時季指定義務**（39条7項、2019年4月〜）: 10日以上付与された労働者への5日取得義務の規定があるか
- 時効: 2年（115条）。「翌年度への繰越は認めない」は違法
- 半日・時間単位年休を認めるなら労使協定が必要（時間単位は39条4項）

### 2. 賃金関係（89条2号）※臨時の賃金等を除く

| 項目 | 確認すること |
|---|---|
| 決定・計算の方法 | 基本給・各種手当の種類と計算方法 |
| 支払の方法 | 通貨払い・直接払い・全額払い（24条）。口座振込は本人同意が前提 |
| 締切り・支払の時期 | 毎月1回以上・一定期日払い（24条2項） |
| 昇給 | 昇給の有無・時期・基準。**「昇給しないことがある」でも記載は必要** |
| 割増賃金 | 時間外25%以上、月60時間超50%以上、深夜25%、法定休日35%（37条、割増賃金令） |
| 欠勤・遅刻控除 | 控除の計算方法。制裁としての減給とは区別されているか |
| 端数処理 | 1か月の時間外時間数の30分未満切捨て等は通達の範囲内か |

**別規程（賃金規程）に委任している場合**: 委任自体は適法。ただし賃金規程も就業規則の一部なので、
届出・意見聴取・周知の対象になる。委任先が存在するか必ず確認する。

### 3. 退職に関する事項（89条3号）※解雇の事由を含む

| 項目 | 確認すること |
|---|---|
| 退職事由 | 自己都合・定年・契約期間満了・死亡・休職期間満了など、退職となる場合の列挙 |
| 退職手続 | 申出の時期。民法627条（期間の定めのない雇用は申入れから2週間）との関係に注意 |
| 定年 | 60歳以上（高年法8条）。65歳までの雇用確保措置（高年法9条）の記載 |
| 解雇事由 | **具体的に列挙されているか**。89条3号は解雇事由の明示を求めている |
| 解雇予告 | 30日前予告または平均賃金30日分の予告手当（20条）。即時解雇できる場合の限定 |

解雇事由が「その他前各号に準ずるやむを得ない事由があるとき」のみ、あるいは包括条項だけの場合は、
解雇の有効性を争われたときに使えないため要検討。

## 相対的必要記載事項（その制度を設ける場合は必ず書く）

制度が無ければ書かなくてよい。**「制度として運用しているのに規程に無い」場合だけが指摘対象**。
運用実態はファイルからは分からないので、疑わしいものは「要確認」に回す。

| 号 | 事項 | 見るポイント |
|---|---|---|
| 3の2 | 退職手当 | 適用者の範囲、決定・計算・支払の方法、支払時期。不支給・減額事由の合理性 |
| 4 | 臨時の賃金等（賞与）、最低賃金額 | 支給対象者の要件（「支給日在籍」要件の書き方）、算定期間 |
| 5 | 食費・作業用品などの労働者負担 | 負担させるなら明記が必要 |
| 6 | 安全衛生 | 健康診断（安衛法66条）、ストレスチェック、就業制限 |
| 7 | 職業訓練 | 受講義務・費用負担。費用返還条項は16条（賠償予定の禁止）に注意 |
| 8 | 災害補償・業務外の傷病扶助 | 労災上乗せ補償、私傷病時の扱い |
| 9 | 表彰・制裁 | **種類と程度の明記が必要**。減給の制限（91条）に注意 → risk-clauses.md |
| 10 | その他全労働者に適用される定め | 休職、服務規律、配置転換・出向、副業、秘密保持、ハラスメント防止、テレワーク |

**休職** は相対的必要記載事項（10号）だが、実務上ほぼ必ず設けられている。
記載がある場合は、休職事由・期間・期間中の賃金・復職の判断方法・期間満了時の扱い（退職か解雇か）が
揃っているかを見る。期間満了時の扱いが書いていないのは典型的な不備。

## 作成・届出・周知の手続（記載事項とは別に確認）

| 義務 | 根拠 | 確認すること |
|---|---|---|
| 作成・届出 | 89条 | 常時10人以上の事業場は作成し所轄労基署に届出。**変更時も届出が必要** |
| 意見聴取 | 90条 | 過半数labor組合、無ければ過半数代表者の意見書を添付。代表者の選出方法（投票・挙手等、使用者が指名は不可） |
| 周知 | 106条、則52条の2 | 掲示・備付け・書面交付・電子データへのアクセス確保のいずれか。**周知していない就業規則は効力が争われる** |
| 附則 | ― | 施行日・改定日の記載。改定履歴が追えるか |

規程本体に「本規則は○年○月○日から施行する」が無い、あるいは前回改定のままになっている場合は形式面で指摘する。

## 別規程がある場合の全体像

就業規則は本則だけとは限らない。以下が別規程になっていることが多く、
**別規程も就業規則の一部として届出・意見聴取・周知の対象** になる。

賃金規程 / 退職金規程 / 育児介護休業規程 / 継続雇用規程 / パートタイマー就業規則 /
嘱託社員就業規則 / 旅費規程 / 安全衛生管理規程 / ハラスメント防止規程 / テレワーク規程 / 副業・兼業規程

本則で言及されているのに存在が確認できない規程は、レポートの「要確認」に列挙する。
特に **パート・有期社員に本則が適用されない旨だけ書いてあって専用規則が無い** ケースは、
その層に適用される就業規則が存在しないことになるため優先度が高い。
