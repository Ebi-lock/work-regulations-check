# 違法・リスクのある条項パターン

実際の就業規則で繰り返し見つかる問題条項。左の「見つけ方」は本文検索の手がかり。
**該当しても即違法とは限らない**ものが混ざっているので、根拠と一緒に程度を判断する。

## A. 明確に法違反となりうるもの（要是正）

### A-1. 減給の制裁が上限を超えている
- **根拠**: 労基法91条
- **上限**: 1回の額が平均賃金の1日分の半額以下、かつ総額が一賃金支払期の賃金総額の10分の1以下
- **見つけ方**: 「減給」「制裁」「懲戒」「けん責」「過怠金」
- **典型例**: 「減給は基本給の10%を上限とする」→ 「一賃金支払期の賃金総額の10分の1」であって基本給ではない。
  「1回の額が平均賃金1日分の半額」の制限が抜けているものが非常に多い
- **注意**: 遅刻・欠勤による不就労分の控除は制裁ではないのでこの制限にかからない。両者が同じ条に
  混在していると誤解を招くため、区別して書くよう促す

### A-2. 賠償額を予定する条項
- **根拠**: 労基法16条（賠償予定の禁止）
- **見つけ方**: 「違約金」「罰金」「損害賠償として○円」「1回につき○円を徴収」
- **典型例**: 「無断欠勤1日につき5,000円を控除する」「研修費用を一律返還する」
- **注意**: 実損害の賠償請求自体は禁止されていない。禁止されるのは**額をあらかじめ定める**こと。
  研修費用の返還は、貸付契約の実質があり返還免除の条件が合理的なら有効とされる余地がある（要検討に置く）

### A-3. 年次有給休暇を許可制にしている / 取得に不利益を課している
- **根拠**: 労基法39条、附則136条
- **見つけ方**: 「有給休暇」「年休」＋「許可」「承認」「認めた場合」
- **典型例**: 「会社の承認を得て取得できる」→ 年休は労働者の請求で成立し、会社にあるのは時季変更権のみ
- **不利益取扱いの例**: 年休取得日を欠勤扱いして精勤手当・賞与を減額する、皆勤手当の対象外にする

### A-4. 退職の申出を過度に制限している
- **根拠**: 民法627条1項（期間の定めのない雇用は申入れから2週間で終了）
- **見つけ方**: 「退職」＋「か月前」「承認」「後任」
- **典型例**: 「退職は6か月前に申し出て、会社の承認を得なければならない」
- **程度の判断**: 「1か月前までに申し出る」程度は引継ぎの合理的要請として実務上広く使われており、
  直ちに違法とは言いにくい（要検討）。「承認がなければ退職できない」「3か月以上前」は要是正寄り

### A-5. 割増賃金率が法定を下回る
- **根拠**: 労基法37条、割増賃金令
- **法定率**: 時間外25%以上 / 1か月60時間超の時間外50%以上 / 深夜（22時〜5時）25%以上 /
  法定休日35%以上。時間外が深夜に及べば合算50%以上
- **見つけ方**: 「割増」「1.25」「25%」「時間外手当」
- **典型例**: 月60時間超50%の規定が無い（中小企業も2023年4月から適用済み）、
  法定休日と所定休日を区別せず一律25%にしている

### A-6. 固定残業代（みなし残業）の要件不足
- **根拠**: 労基法37条、最判平29.7.7（医療法人康心会事件）、最判令2.3.30（国際自動車事件）ほか
- **必要**: ①固定残業代に相当する金額、②何時間分か、③超過分は別途支払う旨 ― の明示と、
  通常の労働時間の賃金部分との判別可能性
- **見つけ方**: 「みなし残業」「固定残業」「定額残業」「営業手当（時間外手当を含む）」
- **典型例**: 「営業手当には時間外手当を含む」だけで時間数も超過分の支払いも書いていない
  → 固定残業代として認められず、手当を含めた額を基礎に未払割増賃金が発生するリスク

### A-7. 全額払い原則に反する控除
- **根拠**: 労基法24条1項
- **見つけ方**: 「控除」「相殺」「天引き」
- **典型例**: 「貸付金・寮費・制服代を賃金から控除する」が労使協定なしに書かれている。
  法定控除（税・社会保険料）以外の控除には**賃金控除に関する労使協定**が必要

### A-8. 定年が60歳未満 / 65歳までの雇用確保措置が無い
- **根拠**: 高年齢者雇用安定法8条・9条
- **典型例**: 定年60歳で再雇用の定めが無い。再雇用の対象者を会社が選別する基準を設けている
  → 労使協定による対象者限定の経過措置は**2025年3月31日で終了**しており、現在は希望者全員が対象

### A-9. 強制貯金・前借金相殺
- **根拠**: 労基法17条・18条
- **見つけ方**: 「社内預金」「積立」「貸付金と相殺」

### A-10. 産前産後・育児介護休業等の不利益取扱い
- **根拠**: 労基法65条、均等法9条、育介法10条ほか
- **典型例**: 育休取得者を昇給・賞与の算定で一律不利に扱う、休業期間を勤続年数から除外して退職金を減らす

## B. 直ちに違法ではないが紛争リスクがあるもの（要検討）

| パターン | リスク | 見るポイント |
|---|---|---|
| 解雇事由が包括的 | 労契法16条（客観的合理性・社会通念上の相当性）で無効になりやすい | 「会社が不適格と認めたとき」のみ、等 |
| 懲戒事由・懲戒種類の定めが無い / 曖昧 | 罪刑法定主義的な考え方により懲戒処分が無効になる | 種類（けん責・減給・出勤停止・降格・諭旨・懲戒解雇）と程度が対応しているか |
| 普通解雇と懲戒解雇の区別が無い | 手続・退職金の扱いで争いになる | |
| 休職期間満了時の扱いが未記載 | 自然退職か解雇かで手続が変わる | 「休職期間満了時に復職できない場合は…」の一文があるか |
| 配置転換・出向の根拠が無い | 個別同意が必要になる | 出向は「出向を命ずることがある」＋出向先の労働条件の定めが要る |
| 副業・兼業の全面禁止 | 労働時間外は原則自由（最判・ガイドライン） | 許可制＋制限事由の限定（労務提供への支障、秘密漏洩、競業）に留めるのが安全 |
| 競業避止義務が無限定 | 期間・地域・職種・代償措置が無いと無効になりやすい | 退職後の競業避止条項の範囲 |
| 身元保証の期間が無記載 | 身元保証法により期間の定めが無い場合は3年、上限5年。**2020年4月以降は極度額の定めが無いと無効** | 「身元保証」の記載 |
| 試用期間が長い / 延長が無限定 | 6か月超は要検討。延長規定は要件と上限を明記 | 試用期間中の解雇も14日超で解雇予告が必要（21条） |
| 服務規律が抽象的 | 懲戒の根拠にならない | |
| 所定労働時間が法定を超える | 1日8時間・週40時間（32条）。特例事業場（商業・映画演劇・保健衛生・接客娯楽で常時10人未満）は週44時間 | |
| 36協定への言及が無い | 時間外命令の根拠が就業規則に必要 | 「業務上必要がある場合は36協定の範囲内で時間外労働を命ずることがある」 |
| 時間外労働の上限規制の記載が無い | 月45時間・年360時間、特別条項でも年720時間・単月100時間未満・複数月平均80時間以内・月45時間超は年6回まで（36条） | |
| ハラスメント防止規定が無い | パワハラ防止措置義務（労働施策総合推進法30条の2、中小企業も2022年4月〜） | 相談窓口・不利益取扱いの禁止まで書かれているか |
| カスハラ対策の規定が無い | 顧客等の言動に関する措置義務（労働施策総合推進法33条、**2026年10月1日施行**） | 相談体制、対応方針、抑止のための措置。施行前は「違反」ではなく「次回改定で織り込む必要がある」と書く |
| パート・有期との待遇差の説明が無い | パート有期法8条・9条（不合理な待遇差の禁止） | 手当の支給要件が正社員限定になっていないか |
| 個人情報・秘密保持の定めが無い | | |

## C. 見落としやすい確認ポイント

- **適用範囲条項**: 「この規則はすべての従業員に適用する」と書きつつ、パート用規則が別にある／無い の齟齬
- **「会社が必要と認めたとき」の多用**: 単体では問題にならないが、解雇・懲戒・不利益変更の場面に
  集中している場合は全体として使用者の裁量が広すぎる構造になっている
- **法改正前の古い用語**: 「育児休業（1歳まで）」だけで延長規定が無い、「子の看護休暇」（現行は「子の看護等休暇」）、
  「セクシュアルハラスメント」のみでパワハラ・マタハラ・カスハラが無い
- **賃金請求権の時効**: 2020年4月以降に発生した賃金は当面3年（労基法115条・附則143条）。
  「2年」と書いてある規程は改正未対応
- **数字の整合**: 所定労働時間×所定労働日数と月平均所定労働時間（割増賃金の基礎）が合っているか。
  年間休日数と休日の定めが矛盾していないか
