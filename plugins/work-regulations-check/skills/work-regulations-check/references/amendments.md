# 法改正対応チェック

**基準日: 2026年9月17日**

## 流れ

```
厚労省の改正情報          何が、なぜ変わるのか。改正の全体像と施行期日の考え方
        ↓                 scripts/mhlw_bills.py
e-Gov で現行法を確認      条文が実際にどう書かれているか。引用できる原文
        ↓                 scripts/fetch_law.py
施行日を確認              いま効いているのか、これから効くのか
        ↓                 scripts/fetch_law.py --status / --asof
就業規則への影響を判定    その規程のどの条を、どう直す必要があるのか
```

順番に意味がある。**e-Gov から始めてはいけない。** e-Gov は「いま条文がどうなっているか」しか
教えてくれないので、条文を読んでも「何が新しいのか」「なぜ入ったのか」が分からない。
逆に厚労省の資料だけで書くと、条文の文言が手に入らず、引用が不正確になる。
両方を、この順で使う。

---

## ステップ1　厚労省の改正情報

改正の全体像は、厚労省の「国会提出法案」にある**概要 PDF** が一番早い。
改正の趣旨、項目ごとの内容、そして**施行期日**が1枚にまとまっている。

```bash
python3 scripts/mhlw_bills.py --sessions        # 掲載されている国会回次
python3 scripts/mhlw_bills.py --session 217     # その回次の労働関係法案と資料
python3 scripts/mhlw_bills.py --summary 217     # 概要PDFを読む（ここが本命）
python3 scripts/mhlw_bills.py --recent 3        # 直近3回次
```

見るのは概要の次の3点。

1. **改正の概要** — 事業主に何の義務が課されたか。「義務付け」「努力義務」「責務」の
   区別が書かれている。努力義務を「違反」と書くと事実と違うので、ここで読み分ける
2. **施行期日** — 「公布の日から起算して1年6月以内で政令で定める日」のように
   幅を持った書き方をしていることが多い。確定日はステップ3で e-Gov から取る
3. **どの法律が変わったか** — 【　】に法律名が並んでいる。ステップ2で引く対象

概要で足りないときは、同じ一覧にある**新旧対照条文**を見ると、どの条がどう変わったかが分かる。

告示・指針（パワハラ指針など）は法案資料には含まれない。必要なら厚労省サイトを
WebSearch で探す。「就業規則にどう書くか」のレベルは指針に書かれていることが多い。

### 厚労省の法案一覧に出てこない改正

労働法が他省庁提出の法案で横断的に改正されることがある。その場合このページには載らない。
ステップ3で `--status` を流したときに、見覚えのない改正法（「令和○年法律第○号」）が
出てきたら、その法律番号で WebSearch して内容を確認する。
`--sessions` に無い回次を指定するとエラーになるので、一覧の範囲で探すこと。

### 改正情報が古い規程に効いているかを見るとき

規程の最終改定日が読めるなら、それ以降に施行された改正だけを追えばよい。
このファイル後半の「施行済みの改正」の表が、その当たりを付けるための一覧。
**ただし表は基準日時点のもの**なので、基準日より後は必ず `mhlw_bills.py --recent` で拾い直す。

## ステップ2　e-Gov で現行法を確認

厚労省の概要は要約なので、そのままレポートの根拠にはできない。条文の原文を取る。

```bash
python3 scripts/fetch_law.py 労施法 33            # 条文
python3 scripts/fetch_law.py 育介法 --grep 看護   # どの条にあるか分からないとき
```

概要の【労働施策総合推進法】という表記から `労施法` を引く、という対応関係になる。
`--list` で略称の一覧が出る。

## ステップ3　施行日を確認

ここが判定の分かれ目になる。**施行済みか未施行かで、指摘の書き方が変わる。**

```bash
python3 scripts/fetch_law.py 労施法 --status
```

- 「現在の版」の施行日 … いま効いている条文
- 「★ 未施行の改正があります」 … その日付で `--asof` を付けて取り直す

### 条番号は改正でずれる

これが一番はまりやすい。**未施行の条番号を現行版で引くと、まったく別の条文が返ってくる。**

労働施策総合推進法の第33条は、その実例。

| 版 | 第33条の中身 |
|---|---|
| 現行（2026年4月1日施行） | 厚生労働大臣による助言・指導・勧告 |
| 2026年10月1日施行 | **職場における顧客等の言動に起因する問題に関する雇用管理上の措置等（カスハラ）** |

改正で条が挿入されると、以降の条番号が繰り下がる。`--asof` を付け忘れたまま
「労働施策総合推進法第33条（カスハラ）」と書くと、根拠として成立しないどころか、
読んだ人が条文を確認した時点で誤りが露見する。

**未施行の改正を扱うときは、必ず `--asof` を付けて条文の中身を目で確認してから引用する。**

```bash
python3 scripts/fetch_law.py 労施法 33 --asof 2026-10-01
```

`--asof` を付けないと改正前の条文が返ってくる。未施行の改正を扱うときは付け忘れに注意する。

同じ改正法でも、項目ごとに施行日が違うことがよくある（概要の施行期日欄に「ただし〜は令和8年4月1日」
のように書かれている）。**改正法単位ではなく、項目単位で施行日を確認する。**

## ステップ4　就業規則への影響を判定

ここまでで「何が・いつから・どう義務付けられたか」が揃う。最後に、目の前の規程に当てはめる。

判定は次の順で行う。

1. **そもそも就業規則に書く事項か**　労基法89条の必要記載事項に当たるか、
   あるいは制度の細目を定めないと運用できないものか。
   労災保険の給付手続のように、規程に書かれないのが普通のものもある
2. **その事業場に適用があるか**　規模要件（常時10人以上、101人以上など）、
   業種、雇用形態。適用がなければ指摘しない（ただし将来の適用は注記する）
3. **既存の条文でカバーされているか**　`check_structure.py` の条文一覧で該当しそうな条を探し、
   本文を読む。「ハラスメント」の条があってもカスハラは対象外、ということがある
4. **施行済みか未施行か**
   - 施行済みで対応なし → **要是正**「未対応（○年○月施行）」
   - 未施行 → **要検討**「○年○月○日から義務化されるため、次回改定で織り込む必要がある」。
     違反ではないので「違反」と書かない
   - 努力義務 → **要検討**。「義務」と書かない

### 影響が小さいと判定してよい例

改正があっても就業規則を直す必要がないものは多い。手を動かす前に切り分ける。

- 給付・保険の手続に関する改正（労災保険の給付内容、時効期間など）
- 公表義務・報告義務（規程ではなく実務の話。ただし対象規模は伝える）
- 国や行政機関の責務に関する規定
- 既に規程が法定を上回っている場合（法改正で法定が引き上がっても、規程が上回っていれば対応不要）

判定に迷ったら、レポートの「要確認」に回して、何を確認すれば決まるのかを書く。

### 書き方の例

```markdown
### カスタマーハラスメント対策の規定がない

**該当箇所**: 第○条（ハラスメントの禁止）にパワハラ・セクハラの定めはあるが、顧客等の言動は対象外

**改正の内容**: 厚生労働省「労働施策総合推進法等の一部を改正する法律案の概要」より、
顧客等の言動により労働者の就業環境が害されることのないよう、相談体制の整備その他
雇用管理上必要な措置を講じることが事業主に義務付けられた。

**根拠**: 労働施策総合推進法第33条（2026年10月1日施行。e-Gov法令検索で確認）
> 事業主は、職場において行われる顧客、取引の相手方、施設の利用者その他の当該事業主の
> 行う事業に関係を有する者の言動であつて…（原文を貼る）

**影響**: 施行日時点で措置義務が生じる。現行規程では相談窓口がパワハラ・セクハラのみを
想定しているため、対象と対応方針の追加が必要。

**対応**: 次回改定で第○条を改め、相談窓口・対応方針・不利益取扱いの禁止を定める。
```

## 補足

### 条文案の作り方

`python3 scripts/model_rules.py --grep <キーワード>` で厚労省の規程例を引き、それに合わせる。

育児・介護休業関係はモデル就業規則に入っていないので `--source ikuji` を使う。
**この領域は改正が最も激しく指摘も集中する**ため、法令条文から自分で起案せず、
必ず規定例を引くこと。産後パパ育休・子の看護等休暇・柔軟な働き方の措置が揃っている。

### 対象者がいない制度について

「うちには育児中の従業員がいないから不要」とは言えない。就業規則は将来の対象者にも適用される。
ただし優先度は下げてよいので、要是正ではなく要検討に置き、その理由を書く。

### このファイルの表が古くなったら

「施行済みの改正」の表は基準日（2026年9月17日）時点のもの。基準日より後にチェックするときは、
`python3 scripts/mhlw_bills.py --recent 3` で直近の国会提出法案を拾い、
表に無い改正が出ていないか確認してから使う。表を信じきらないこと。
