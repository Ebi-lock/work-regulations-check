# 社内規程との整合性・運用との一致

条文だけを見ていると見つからない誤りがある。就業規則は単体では完結せず、
**別規程・労働協約・個別の契約書・実際の運用**と噛み合って初めて機能する。

この観点の指摘は、**手元に無い書面については断定しない。** 「矛盾している」ではなく
「突き合わせが必要」として要確認に回す。無いものを推測で指摘すると信用を失う。

---

## 1. 規程間の整合性

### 何と突き合わせるか

`check_structure.py` の「本文から参照されている別規程・別表」に出たものが出発点。
本則が委任している先は必ず確認対象になる。

| 規程 | 就業規則本則と食い違いやすい点 |
|---|---|
| 賃金規程 | 手当の種類、割増賃金の計算基礎、締切日・支払日、昇給時期 |
| 育児・介護休業規程 | 対象者の範囲、休業期間、賃金の取扱い、**改正対応の有無** |
| パート・有期雇用規程 | 適用範囲の裏返しが一致するか、年休の比例付与、待遇差の説明 |
| 退職金規程 | 支給対象者の範囲、勤続年数の計算（休職期間を算入するか） |
| テレワーク規程 | 労働時間の管理方法、費用負担、中抜けの扱い |
| 個人情報・情報セキュリティ規程 | 服務規律との重複と矛盾、違反時の懲戒との接続 |
| 旅費規程 | 出張中の労働時間の扱い |

### 典型的な食い違い

| パターン | 何が起きるか |
|---|---|
| 本則「賃金は別に定める賃金規程による」だが賃金規程が存在しない | 賃金に関する定めが無いことになる（労基法89条2号違反） |
| 本則の適用範囲が「正社員」だがパート就業規則が無い | その層に適用される就業規則が存在しない |
| 本則の手当一覧と賃金規程の手当一覧が違う | どちらが適用されるか不明 |
| 育児介護休業規程が改正前のまま | 本則で「別規程による」としているため、改正未対応がそのまま効く |
| 退職金規程で休職期間を勤続年数から除外、本則に記載なし | 不利益な取扱いの根拠が不明確 |
| 服務規律とセキュリティ規程で禁止行為が重複し、内容が微妙に違う | どちらの違反として処分するかで争いになる |

### 適用範囲の裏返しを必ず確認する

本則第2条（適用範囲）で除外した層について、**その層の規則が存在するか**を確認する。
これは最も頻出する構造的な穴で、条文だけを読んでいると気づかない。

```
本則「この規則は正社員に適用する」
  → パート・有期・嘱託がいるか？
    → いる → その層の就業規則はあるか？
      → 無い → 要是正（その層に適用される就業規則が存在しない）
      → ある → 内容を確認する必要がある（要確認）
    → いない → 問題なし。ただし将来雇う場合は要る旨を注記
```

### 別規程も就業規則の一部

**「別規程だから届出不要」は誤り。** 別規程も就業規則の一部であり、
作成・変更のたびに意見聴取（労基法90条）と届出（同89条）、周知（同106条）が要る。
別規程だけ改定して届け出ていないケースは多いので、手続の有無を確認する。

## 2. 上位規範との整合性

### 労働協約

**労働協約に反する就業規則は、その部分が無効になる**（労基法92条、労働契約法13条）。
労働組合がある事業場では、協約の有無と内容を確認する。行政官庁は協約に反する就業規則の
変更を命じることができる（労基法92条2項）。

### 法令

法令に反する就業規則も無効（労基法92条、労働契約法13条）。これは `required-items.md`
`risk-clauses.md` `amendments.md` の観点。

### 個別の労働契約

就業規則で定める基準に達しない労働条件を定める労働契約は、その部分が無効となり、
**就業規則の基準による**（労働契約法12条）。逆に、就業規則を上回る個別合意は有効。

つまり **就業規則は最低ライン** として働く。ここを取り違えると、
「契約書にこう書いてあるから大丈夫」という誤った説明になる。

## 3. 運用との一致

規程の文面が正しくても、実際の運用が違えば意味がない。
**運用はファイルからは分からない。** 聞くか、要確認に回す。

### 突き合わせる書面

| 書面 | 確認すること |
|---|---|
| 労働条件通知書・雇用契約書 | 就業規則と食い違っていないか。**2024年4月から明示事項が増えている**（就業場所・業務の変更の範囲、有期の更新上限、無期転換申込機会） |
| 36協定 | 締結・届出しているか。規程が時間外労働を予定しているのに36協定が無いのは重大 |
| 各種労使協定 | 賃金控除、時間単位年休、計画的付与、変形労働時間制、育介の適用除外、休憩の一斉付与の除外 |
| 賃金台帳・給与明細 | 規程の手当と実際の支給項目が一致するか |
| 勤怠記録 | 規程の始業終業時刻と実態が一致するか |
| 意見書 | 過半数代表者の選出方法。**会社が指名していないか** |
| 届出の控え | 労基署の受付印。変更のたびに届け出ているか |

### 労使協定が必要なのに無いと制度が成立しないもの

規程に書いてあっても、労使協定が無ければ運用できない。**規程だけ見て「対応済み」と
判断しない。**

- 賃金からの法定外控除（労基法24条1項ただし書）
- 時間単位年休（同39条4項）
- 年休の計画的付与（同39条6項）
- 休憩の一斉付与の適用除外（同34条2項ただし書）
- 変形労働時間制（1年単位・1週間単位は協定必須。1か月単位は規則でも可）
- フレックスタイム制（同32条の3）
- 事業場外みなし労働時間制で所定超えの場合（同38条の2）
- 裁量労働制（同38条の3、38条の4）
- 育児介護休業の対象者からの除外（育介法6条ほか）
- 時間外・休日労働（36協定。同36条）

### 運用が規程と違うときの扱い

実態が規程を上回っている（規程より手厚い）場合、その運用が労働条件として定着していると
評価されることがある。規程を実態に合わせるか、運用を規程に合わせるかの判断が要る。

実態が規程を下回っている場合は、**就業規則の基準が適用される**（労働契約法12条）ため、
未払いが発生している可能性がある。これは見つけたら優先度を上げる。

## 4. 手続の履行

規程の中身が正しくても、手続を欠くと効力を争われる。

| 手続 | 根拠 | 確認すること |
|---|---|---|
| 意見聴取 | 労基法90条 | 過半数組合、無ければ過半数代表者の意見書。**「同意」ではなく「意見を聴く」で足りる**が、聴かないのは違法 |
| 代表者の選出 | 則6条の2 | 投票・挙手等の民主的な方法。**会社の指名は不可**。管理監督者は代表になれない |
| 届出 | 労基法89条 | 常時10人以上の事業場。**変更のたびに**必要。就業規則＋意見書＋変更届 |
| 周知 | 労基法106条、則52条の2 | 配付、見やすい場所への掲示・備付け、電子データへのアクセス確保。**周知していない就業規則は効力を争われる** |

### 不利益変更

労働条件を労働者に不利に変更する場合、原則として労働者の同意が要る（労働契約法9条）。
同意なく変更するには、変更の合理性（不利益の程度、変更の必要性、内容の相当性、
交渉の経緯等）が問われる（同10条）。

**改定の指摘をするときは、それが不利益変更に当たるかを必ず判定する。**
「こう直すべき」と書いた内容が不利益変更なら、手続を書き添えないと実行できない。

## 5. 運用開始後の見直し

就業規則は一度作って終わりではない。レポートの最後に、次の循環を回す必要があることを書く。

```
法改正 → 自社制度への影響確認 → 就業規則の確認 → 改定
  → 意見聴取 → 届出 → 周知 → （次の改正へ）
```

**特に育児介護休業法は毎年のように改正される。** 年1回は `mhlw_bills.py --recent 3` と
`fetch_law.py <法令> --status` で施行状況を確認する運用を勧める。

改定履歴が附則で追える状態になっているかも確認する。いつ何を変えたか分からない規程は、
次の改定のときに判断できない。
