# 聞き取り項目

就業規則は事業場ごとに違うから作る意味がある。ここを埋めずに書くと、ただのひな形コピーになる。

**相手は規程の専門家ではない。** 白紙から答えさせず、モデル就業規則の既定値を選択肢として示す。
「休憩は何分ですか」ではなく「モデル就業規則は正午から60分です。これで進めますか」と聞く。

答えが出ない項目は推測で埋めない。保留にして、最後に「決める必要がある項目」として出す。

---

## 第1段階：これが無いと条文が書けない

| 項目 | 聞き方 | 既定値・注意 |
|---|---|---|
| 会社名 | 正式名称（株式会社の位置も） | 条文冒頭と附則に入る |
| 事業内容 | 業種 | 特例事業場かの判定に要る |
| 常時使用する労働者数 | パート・アルバイトを含めた人数 | **10人以上なら作成・届出義務**（労基法89条） |
| 事業場の数 | 本社のみか、支店等があるか | 届出は事業場ごと |
| 適用対象 | 正社員のみか、パート・有期・嘱託も含むか | 正社員のみなら、他の層の規則が別に要る |
| 呼称 | 「従業員」「社員」「職員」のどれを使うか | 規程全体で統一する |
| 始業・終業の時刻 | 具体的な時刻 | 例: 午前9時〜午後6時 |
| 休憩 | 時刻と長さ | 6時間超45分、8時間超60分（労基法34条）。一斉付与が原則 |
| 所定労働時間 | 1日・1週 | 1日8時間・週40時間が上限（同32条） |
| 休日 | 曜日と、**どれが法定休日か** | 法定休日が特定できないと休日割増（35%）の日が決まらない |
| 年間休日数 | 日数 | 夏季・年末年始を含むか |
| 賃金の締切日 | 毎月〇日 | |
| 賃金の支払日 | 毎月〇日 | 毎月1回以上・一定期日（同24条） |

## 第2段階：制度の有無だけ先に聞く

あるかないかだけ。「ある」と答えたものだけ第3段階で細目を聞く。

| 制度 | 無ければ | 注意 |
|---|---|---|
| 試用期間 | 条文を置かない | 置くなら期間と延長の扱い |
| 変形労働時間制・フレックス | 条文を置かない | **運用しているのに規程に無いと制度が無効**。必ず確認する |
| 諸手当 | 基本給のみ | 種類を列挙する |
| 賞与 | 条文を置かない | 相対的必要記載事項 |
| 退職金 | 条文を置かない | 相対的必要記載事項。あるなら別規程が扱いやすい |
| 休職 | 条文を置かない | 実務上はほぼ必要。無いと長期欠勤者の扱いが決まらない |
| 定年 | 条文を置かない | 置くなら60歳以上（高年法8条）＋65歳までの雇用確保措置（同9条） |
| 出張・旅費 | 条文を置かない | 別規程にすることが多い |
| 副業・兼業 | 条文を置かない | 全面禁止は避ける |
| テレワーク | 条文を置かない | あるなら費用負担と労働時間管理 |
| 育児・介護休業 | **条文は必要** | 法定制度なので必ず要る。別規程にするのが原則 |
| ハラスメント防止 | **条文は必要** | 措置義務（労働施策総合推進法30条の2ほか） |
| 安全衛生・健康診断 | **条文は必要** | 健診は法定義務（安衛法66条） |

## 第3段階：細目

「ある」と答えた制度についてだけ聞く。

### 労働時間まわり
- 変形労働時間制の種類（1か月単位／1年単位／フレックス）と清算期間
- フレックスのコアタイム・フレキシブルタイムの有無
- 交替制があるなら、交替順序と就業時転換の方法
- 時間外・休日労働をさせるか（**36協定の締結・届出が前提**）

### 賃金まわり
- 手当の種類と、それぞれの支給要件・計算方法
- 割増賃金の計算基礎から除外する手当があるか（家族・通勤・住宅手当等は法定除外あり）
- 固定残業代を使うか（使うなら**金額・時間数・超過分を支払う旨**の3点が必須）
- 昇給の時期と基準
- 欠勤・遅刻控除の計算方法
- 賃金からの控除（法定控除以外は**労使協定が必要**）
- 賞与の算定期間と支給対象者の要件（支給日在籍要件を置くか）

### 休暇まわり
- 年休の付与基準日（入社日起算か一斉付与か）
- 比例付与の対象者がいるか
- 半日単位・時間単位の年休を認めるか（時間単位は**労使協定が必要**）
- 年5日の時季指定をどう運用するか
- 慶弔休暇などの特別休暇の有無と日数、有給か無給か

### 退職・解雇まわり
- 退職の申出時期（**過度に長くできない**。民法627条1項は2週間）
- 定年年齢と、定年後の再雇用の扱い
- 解雇事由として何を挙げるか
- 休職の事由・期間・期間中の賃金・復職の判断方法・**期間満了時の扱い**

### 服務・懲戒まわり
- 服務規律に何を入れるか（秘密保持、競業、SNS、持ち出し）
- 懲戒の種類（けん責・減給・出勤停止・降格・諭旨退職・懲戒解雇）
- 懲戒事由として何を挙げるか
- **懲戒の程度**（種類だけでなく程度の記載が必要。労基法89条9号）

### その他
- 身元保証を取るか（取るなら**極度額の定めが必須**。改正民法465条の2）
- 個人情報・健康情報の取扱い
- 施行日

## 聞き取りの進め方

### 一度に全部聞かない

第1段階だけで13項目ある。まとめて投げると答えが返ってこない。
5〜6項目ずつ、まとまりごとに聞く。

### 分からないと言われたら

「一般的にはこうです」と既定値を示して、それでよいか確認する。
モデル就業規則の解説（`model_rules.py --explain`）に、その規定を置く理由と
事業場ごとに変えてよい範囲が書かれているので、根拠として使える。

それでも決まらなければ保留にする。**保留は失敗ではない。**
決まっていないことが可視化されるほうが、適当な数字を入れられるよりはるかによい。

### 矛盾に気づいたら、その場で確認する

聞き取った内容同士が噛み合わないことがよくある。

- 所定労働時間8時間・休憩45分 → 8時間超で休憩60分が要る（実労働8時間ちょうどなら45分で可だが、残業すると違法になる）
- 始業9時・終業18時・休憩60分 → 実労働8時間。整合する
- 始業8時・終業18時・休憩60分 → 実労働9時間で32条違反
- 年間休日105日・完全週休2日＋祝日 → 日数が合わない
- 「パートはいない」と言いつつ適用範囲を正社員限定 → 限定する必要がない

**後でまとめて指摘するより、その場で聞き返すほうが早い。**
相手も気づいていないことが多い。
