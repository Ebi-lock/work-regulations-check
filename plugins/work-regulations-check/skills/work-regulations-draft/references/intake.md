# 聞き取り項目

就業規則は事業場ごとに違うから作る意味がある。ここを埋めずに書くと、ただのひな形コピーになる。

**相手は規程の専門家ではない。** 白紙から答えさせず、モデル就業規則の既定値を選択肢として示す。
「休憩は何分ですか」ではなく「モデル就業規則は正午から60分です。これで進めますか」と聞く。

答えが出ない項目は推測で埋めない。保留にして、最後に「決める必要がある項目」として出す。

**一度に全部聞かない。** 下の段階ごとに区切って聞く。

---

## 段階1　対象となる事業場・従業員

最初にここを確認しないと、そもそも何を作るのかが決まらない。

| 項目 | 聞くこと | なぜ要るか |
|---|---|---|
| 会社名 | 正式名称（株式会社の位置も） | 条文冒頭と附則 |
| 事業内容 | 業種 | 特例事業場かの判定 |
| 事業場の数 | 本社のみか、支店・営業所・工場があるか | **届出は事業場ごと**。事業場ごとに規則が違うこともある |
| 事業場ごとの人数 | 各事業場で常時何人か | **常時10人以上の事業場は作成・届出義務**（労基法89条） |

### 雇用形態の内訳（事業場ごとに）

ここを雑に聞くと、あとで「その層に適用される規則が無い」という穴があく。

| 雇用形態 | 人数 | 確認すること |
|---|---|---|
| 正社員 | | |
| パート・アルバイト | | **10人の計算に含まれる**。専用規則を作るか |
| 契約社員（有期） | | 更新上限、無期転換の運用 |
| 嘱託社員 | | |
| 定年後再雇用 | | 処遇が正社員と違うなら別規則か別章 |
| 派遣を受け入れているか | | 受入側の規則は適用されないが、服務は影響する |

**「常時10人」はパート・アルバイトを含めて数える。** 正社員だけで判定しない。
繁忙期だけ10人を超える場合も「常時」に当たりうるので、迷ったら専門家確認に回す。

## 段階2　労務制度の洗い出し

「この会社では実際にどう働いているのか」を整理する。

### 労働時間

| 項目 | 確認すること |
|---|---|
| 始業・終業の時刻 | 具体的な時刻。部署で違うなら全部 |
| 休憩 | 時刻と長さ。6時間超45分、8時間超60分（労基法34条）。**一斉付与が原則** |
| 所定労働時間 | 1日・1週。1日8時間・週40時間が上限（同32条） |
| 時間外労働 | させるか。させるなら**36協定の締結・届出が前提** |
| 休日労働 | させるか |
| 深夜労働 | あるか（22時〜5時） |
| フレックスタイム | 使うか。清算期間、コアタイム・フレキシブルタイムの有無 |
| 変形労働時間制 | 使うか。1か月単位／1年単位／1週間単位のどれか |
| 裁量労働制 | 使うか。専門業務型／企画業務型。**専門業務型は本人同意が必要**（2024年4月〜） |
| テレワーク | あるか。費用負担、労働時間の管理方法、中抜けの扱い |
| シフト勤務・交替制 | あるか。あるなら**交替順序と就業時転換の方法**が必要記載事項 |
| 事業場外みなし | 使うか |

**変形労働時間制・フレックス・裁量労働制は、就業規則に根拠が無いと制度自体が無効になる。**
「運用しているか」を必ず聞く。運用しているのに規程に無いのが典型的な不備。

### 休日・休暇

| 項目 | 確認すること |
|---|---|
| 休日 | 曜日と、**どれが法定休日か**。特定しないと休日割増（35%）の日が決まらない |
| 年間休日数 | 日数。夏季・年末年始を含むか |
| 振替休日・代休 | 運用しているか。両者は別物なので区別する |
| 年次有給休暇 | 付与基準日（入社日起算か一斉付与か）、比例付与の対象者がいるか |
| 半日休暇 | 認めるか |
| 時間単位年休 | 認めるか。**労使協定が必要**（労基法39条4項） |
| 計画的付与 | 行うか。**労使協定が必要** |
| 年5日の時季指定 | どう運用するか（2019年4月〜の義務） |
| 慶弔休暇 | あるか。事由別の日数、有給か無給か |
| 夏季休暇 | あるか。日数、有給か無給か |
| 年末年始休暇 | 休日として扱うか、休暇として扱うか |
| その他の特別休暇 | 病気休暇、不妊治療休暇、裁判員休暇、ボランティア休暇など |

### 賃金

| 項目 | 確認すること |
|---|---|
| 基本給 | 月給・日給・時給のどれか。決定要素 |
| 各種手当 | 種類と、それぞれの支給要件・計算方法 |
| 固定残業代 | 使うか。使うなら**金額・時間数・超過分を支払う旨**の3点が必須 |
| 時間外割増 | 25%以上。**月60時間超は50%以上**（中小も2023年4月〜） |
| 深夜割増 | 25%以上。時間外と重なれば合算50%以上 |
| 休日割増 | 法定休日35%以上。所定休日との区別 |
| 割増の計算基礎 | 除外できる手当（家族・通勤・住宅手当等）の扱い |
| 賞与 | あるか。算定期間、支給対象者の要件（支給日在籍要件を置くか） |
| 昇給 | 時期と基準。**「昇給しないことがある」でも記載は必要** |
| 賃金締切日 | 毎月〇日 |
| 賃金支払日 | 毎月〇日。毎月1回以上・一定期日（労基法24条） |
| 支払方法 | 口座振込か。**本人同意が前提** |
| 控除 | 法定控除以外があるか。**労使協定が必要** |
| 欠勤・遅刻・早退 | 控除の計算方法。**制裁としての減給とは区別する** |
| 非常時払い | 制度を置くか（労基法25条） |

## 段階3　人事制度

### 採用・異動

採用手続、試用期間（期間・延長の有無・延長の要件）、労働条件の明示、配属、配転、転勤、出向、
休職（事由・期間・期間中の賃金・復職の判断方法・**期間満了時の扱い**）、復職後の再休職の扱い。

**2024年4月から労働条件の明示事項が増えた。** 就業場所・業務の**変更の範囲**、有期契約の
更新上限、無期転換申込機会と転換後の労働条件。配転条項と労働条件通知書の整合を確認する。

**出向を命じるなら、就業規則に根拠と出向先の労働条件の定めが要る。**

### 退職・解雇

自己都合退職（申出時期。**過度に長くできない**。民法627条1項は2週間）、定年（年齢）、
定年後再雇用（**希望者全員が対象**。選別基準を置く経過措置は2025年3月末で終了）、
休職期間満了（自然退職か解雇か）、普通解雇、懲戒解雇、**解雇事由**、退職手続、
退職時の証明（労基法22条）、貸与品の返還、引継ぎ。

**解雇事由は必須記載事項**（労基法89条3号）。包括条項だけでは、争われたときに使えない。

## 段階4　服務規律・懲戒

ここは規程の性格が最も出る部分。**会社が何を問題視するかは事業内容で違う。**

### 服務

会社の指示への従属、遅刻・早退・欠勤の届出、無断欠勤、職務専念、秘密保持、競業、
各種ハラスメント（パワハラ・セクハラ・マタハラ・カスハラ）、SNS利用、情報セキュリティ、
PC・スマートフォンの利用、私物の持込み・業務利用、会社財産の私的利用、個人情報の取扱い、
インサイダー情報、副業・兼業、反社会的勢力との関係遮断。

**業種で重みが変わる。** 顧客情報を扱うならセキュリティと個人情報を厚く、
接客業ならカスハラと SNS を厚く。一律に並べず、何が実際の問題かを聞く。

### 懲戒

| 種類 | 置くか | 程度 |
|---|---|---|
| 戒告・譴責 | | 始末書の提出を求めるか |
| 減給 | | **1回は平均賃金1日分の半額以下、総額は一賃金支払期の賃金総額の10分の1以下**（労基法91条） |
| 出勤停止 | | 日数の上限、期間中の賃金 |
| 降格 | | |
| 諭旨退職 | | |
| 懲戒解雇 | | 予告手当の扱い、退職金の扱い |

### 行為と処分の対応関係

**種類を並べるだけでは足りない。** 労基法89条9号は制裁の「種類**及び程度**」の記載を求めている。
どの行為がどの処分に当たるのかを書かないと、実際に処分したときに根拠を示せない。

聞き方としては、次の2段構えが答えやすい。

1. **軽い処分（戒告・減給・出勤停止）に当たる行為** — 遅刻・欠勤を繰り返す、職務怠慢、
   届出を怠る、軽微な業務命令違反 など
2. **重い処分（諭旨退職・懲戒解雇）に当たる行為** — 重大な経歴詐称、正当な理由のない無断欠勤が
   続く、横領・背任、暴行、重大な情報漏洩、有罪判決 など

## 段階5　安全衛生・福利厚生

健康診断（一般・特殊・雇入時）、受診義務と結果の取扱い、長時間労働者の面接指導、
ストレスチェック、メンタルヘルス（休職との接続）、安全衛生教育、安全衛生委員会、
災害補償（労災の上乗せ補償を置くか）、慶弔見舞金、社宅・寮、食事の提供、
制服・作業用品（**費用を労働者に負担させるなら記載が必要**。労基法89条5号）。

## 段階6　育児・介護・多様な働き方

**改正が最も激しい領域。** ここは `--source ikuji` の規定例を使う。

育児休業、出生時育児休業（産後パパ育休）、介護休業、子の看護等休暇（**小3修了まで・事由拡大**、
2025年4月〜）、介護休暇、育児・介護のための短時間勤務、所定外労働の制限（**小学校就学前まで**、
2025年4月〜）、時間外労働の制限、深夜業の制限、柔軟な働き方を実現するための措置
（**2025年10月〜、3歳以上小学校就学前について2つ以上**）、妊娠・出産に関する制度
（産前産後休業、母性健康管理、育児時間、生理休暇）、育休等の個別周知・意向確認、
介護離職防止の措置。

あわせて、多様な正社員（勤務地限定・職務限定・時間限定）を置くか、
無期転換（労契法18条）の申込みへの対応をどう書くかを確認する。

## 段階7　他の規程・書面との関係

就業規則だけを見ていると矛盾に気づけない。**既にあるものを出してもらう。**

| 書面 | 確認すること |
|---|---|
| 労働協約 | あるか。**労働協約に反する就業規則は無効**（労基法92条、労契法13条） |
| 雇用契約書・労働条件通知書 | 実際に使っている様式。就業規則と食い違っていないか |
| 賃金規程 | あるか。本則と手当の種類が一致するか |
| 育児・介護休業規程 | あるか。改正対応済みか |
| パート・有期雇用規程 | あるか。**無ければその層に適用される規則が無い** |
| 退職金規程 | あるか |
| テレワーク規程 | あるか |
| 個人情報・情報セキュリティ規程 | あるか。服務規律との重複・矛盾 |
| 36協定 | 締結・届出しているか。特別条項の有無 |
| 各種労使協定 | 賃金控除、時間単位年休、計画的付与、変形労働時間制、育介の除外 |

**新規作成でも、既にある書面との整合は必ず確認する。**
就業規則だけ新しくして労働条件通知書が古いままだと、どちらが適用されるかで争いになる。

施行日、既存の規程を置き換えるのか新設か、意見聴取の相手（過半数組合の有無）、
届出先の労基署、周知の方法。

## 聞き取りの進め方

### 一度に全部聞かない

段階1と段階2の労働時間だけで20項目近くある。まとめて投げると答えが返ってこない。
**5〜6項目ずつ、まとまりごとに聞く。**

段階3以降は「制度があるかないか」を先にまとめて聞き、「ある」と答えたものだけ細目に入る。

### 分からないと言われたら

「一般的にはこうです」と既定値を示して、それでよいか確認する。
モデル就業規則の解説（`model_rules.py --grep <語> --explain`）に、その規定を置く理由と
事業場ごとに変えてよい範囲が書かれているので、根拠として使える。

それでも決まらなければ保留にする。**保留は失敗ではない。**
決まっていないことが可視化されるほうが、適当な数字を入れられるよりはるかによい。

### 矛盾に気づいたら、その場で確認する

聞き取った内容同士が噛み合わないことがよくある。相手も気づいていない。

| 聞き取った内容 | 何がおかしいか |
|---|---|
| 所定8時間・休憩45分 | 残業すると8時間超になり、休憩60分が要る（労基法34条） |
| 始業8時・終業18時・休憩60分 | 実労働9時間で32条違反 |
| 年間休日105日・完全週休2日＋祝日 | 日数が合わない |
| 「パートはいない」＋適用範囲を正社員限定 | 限定する必要がない |
| 「変形労働時間制は使っていない」＋シフトで週の労働時間が変動 | 実質的に変形制の運用になっている |
| 固定残業代あり＋時間数の定めなし | 固定残業代として認められないおそれ |
| 定年60歳＋再雇用の定めなし | 65歳までの雇用確保措置が要る（高年法9条） |
| 「賃金規程がある」＋手当の種類が本則と違う | どちらが適用されるか不明 |

**後でまとめて指摘するより、その場で聞き返すほうが早い。**
