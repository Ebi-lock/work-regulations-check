# 組み立て方

## 本則の章立て

厚生労働省「モデル就業規則」の構成。これに沿うと、必要記載事項が自然に埋まる。

| 章 | 内容 | 入れる条の例 |
|---|---|---|
| 第1章 | 総則 | 目的、適用範囲、規則の遵守 |
| 第2章 | 採用、異動等 | 採用手続、提出書類、試用期間、労働条件の明示、人事異動、休職 |
| 第3章 | 服務規律 | 服務、遵守事項、各種ハラスメントの禁止、個人情報保護 |
| 第4章 | 労働時間、休憩及び休日 | 始業終業時刻の記録、労働時間及び休憩時間、休日、時間外及び休日労働、勤務間インターバル |
| 第5章 | 休暇等 | 年次有給休暇、産前産後、母性健康管理、育児時間・生理休暇、慶弔休暇、病気休暇、裁判員休暇 |
| 第6章 | 賃金 | 賃金の構成、基本給、各種手当、割増賃金、休暇等の賃金、欠勤等の扱い、計算期間・支払日、支払と控除、非常時払い、昇給、賞与 |
| 第7章 | 定年、退職及び解雇 | 定年等、退職、解雇 |
| 第8章 | 退職金 | 支給、額、支払方法及び支払時期 |
| 第9章 | 無期労働契約への転換 | |
| 第10章 | 安全衛生及び災害補償 | 遵守事項、健康診断、面接指導、ストレスチェック、心身の状態に関する情報の取扱い、安全衛生教育、災害補償 |
| 第11章 | 職業訓練 | 教育訓練 |
| 第12章 | 表彰及び制裁 | 表彰、懲戒の種類、懲戒の事由 |
| 第13章 | 公益通報者保護 | |
| 第14章 | 副業・兼業 | |

**章は事業場に無い制度を落として詰める。** 退職金制度が無ければ第8章は置かない。
章番号は詰めて振り直す（第8章を飛ばして第9章にしない）。

### 必ず置く章

労基法89条の絶対的必要記載事項に対応するので、これが欠けると規則として成立しない。

- 第4章（労働時間、休憩及び休日）
- 第5章のうち年次有給休暇
- 第6章（賃金）— 別規程に委任する場合でも、委任する条は本則に置く
- 第7章（定年、退職及び解雇）

育児・介護休業、ハラスメント防止、健康診断は法定制度なので、制度の有無にかかわらず必要。

## 別規程に切り出す基準

| 規程 | 切り出す目安 | 委任条文の書き方 |
|---|---|---|
| 賃金規程 | 手当が5種類を超える、等級・評価制度がある、従業員50人以上 | 「賃金に関する事項は、別に定める賃金規程による。」 |
| 育児・介護休業規程 | **原則いつでも切り出す** | 「育児休業、介護休業等に関する事項は、別に定める育児・介護休業規程による。」 |
| 退職金規程 | 退職金制度がある | 「退職金に関する事項は、別に定める退職金規程による。」 |
| パートタイマー就業規則 | 正社員以外がいる | 本則第2条（適用範囲）で除外し、別規則を作る |
| 旅費規程 | 出張が頻繁 | |
| ハラスメント防止規程 | 相談体制を詳しく定める場合 | 本則にも禁止規定は残す |

### 切り出すときの注意

**別規程も就業規則の一部**なので、作成・変更のたびに意見聴取と届出が要る（労基法89条・90条）。
「別規程だから届出不要」ではない。

**委任先が存在しない状態で終わらせない。** 本則に「別に定める賃金規程による」と書いて
賃金規程が無ければ、賃金に関する定めが存在しないことになり、89条2号違反になる。
本則だけ作って終わる場合は、**作成が必要な規程として明示的に列挙する**。

### パート・有期を除外するときの落とし穴

本則第2条で「この規則は正社員に適用する」とだけ書いて、パートタイマー就業規則を作らないと、
**その層に適用される就業規則が存在しない**ことになる。よくある不備。

除外するなら、同時に次のどちらかを決める。
- パートタイマー就業規則を作る（別途作成リストに入れる）
- 本則を適用し、異なる部分だけ個別に定める

## 条文を選ぶときの判断

### 規程例に選択肢があるとき

モデル就業規則には「〜する例」「〜しない例」のように複数の書き方が並ぶ条がある
（定年等、労働時間及び休憩時間、休日など）。聞き取った事情に合うものを選び、
**なぜそれを選んだかを相手に伝える。** 選択したこと自体を伝えないと、
あとで「そんな制度にした覚えはない」となる。

育児・介護休業等の規定例では「ケース①②③」の形で並ぶ。有期雇用労働者の扱いや
労使協定による除外の有無で変わるので、聞き取り結果と突き合わせて選ぶ。

### 法定を上回る条文を置くとき

法定より手厚い制度（年休の付与日数を多くする、休憩を長くする等）は当然置いてよい。
ただし**一度規程に書くと労働条件になり、下げるには不利益変更の手続が要る**。
「将来下げる可能性があるか」を確認してから入れる。

### 入れないほうがよい条文

- 運用しない制度の条文 — 規程にあって運用がないと、争いになったとき不利に働く
- 「会社が必要と認めたとき」の多用 — 単体では問題ないが、解雇・懲戒・不利益変更の場面に
  集中すると、全体として使用者の裁量が広すぎる構造になる
- 賠償額をあらかじめ定める条項 — 労基法16条違反
- 年休を許可制にする条項 — 労働者の請求で成立するので、許可制にはできない

## 附則の書き方

本則の末尾に必ず置く。施行日が無いと、いつから効力を持つ規則なのか分からない。

```
附　則
1 この規則は、〇年〇月〇日から施行する。
```

改定の場合は履歴を残す。

```
附　則
1 この規則は、〇年〇月〇日から施行する。
2 この規則は、〇年〇月〇日一部改正し、同日から施行する。
```

## 出力形式

### Markdown（既定）

条見出しは `### 第1条（目的）` の形にする。`check_structure.py` が条見出しを
拾えるので、そのまま自己点検にかけられる。

### Word

`python-docx` で作る（`pip3 install python-docx`）。
見出しスタイルを使うと目次が自動生成でき、社内で回覧しやすい。

**条番号に Word の自動採番を使わない。** 自動採番で振った番号は、
テキスト抽出したときに消える。あとで点検や差分比較ができなくなる。
番号は文字として書く。

## 納品時に添えるもの

規程本体だけでは届出できない。次の3つを必ず添える。

1. **決める必要がある項目** — 保留にした項目を、該当条と一緒に一覧にする
2. **別途作成が必要な規程** — 本則で委任した先を列挙する
3. **届出までの手順** — 専門家確認 → 意見聴取 → 届出 → 周知

### 意見聴取で間違えやすい点

- 過半数代表者は**投票・挙手などの民主的な方法**で選ぶ。会社が指名してはいけない
- **管理監督者（労基法41条2号）は代表者になれない**
- 意見書は「異議なし」でなくてもよい。反対意見でも添付すれば届出は受理される
- パート・有期に関する規則を作るときは、その層の代表者の意見も聴くよう努める
  （パート有期法7条）

### 周知

届け出ただけでは足りない。周知していない就業規則は効力を争われる（労基法106条、則52条の2）。
配付、見やすい場所への掲示・備付け、電子データへのアクセス確保のいずれかを行う。
